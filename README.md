# Sales-Analysis
A PowerBI analysis performed on a synthetic sales dataset in order to draw actionable insights.
Project Background: The dataset used for this analysis was gotten from Kaggle. The columns in this sales dataset include Order ID, Order date, Customer name, City, State, Region, Country, Category,Sub - Category, Product name, Quantity, Unit Price, Revenue, Profit, Month Name and Month. The project focuses on sales analysis, therefore only KPIs and key metrics directly affecting sales were analyzed.

Data cleaning process: The dataset was mostly clean. However, the order date column contained data which was recognized as texts rather than numbers. This was corrected by changing the data type using Power Query.

RECOMMENDATIONS
Given the spike of purchases and volume of quantities ordered in November, this is indicative of seasonal purchases. To further increase profits during this time, implementation of customer reward system should be implemented.
In the other months where sales seem to drop, Black Friday deals and other discount sales should be implemented to boost sales in these months.
